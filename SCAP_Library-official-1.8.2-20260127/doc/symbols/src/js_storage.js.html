 80                         convertedRes.errorCode = res.payload.errorCode;
 81                         convertedRes.errorText = res.payload.errorText;
 82                         reqParams.onFailure(convertedRes);

 84                 }

166     /**
167      * <p>
168      * This section describes the SCAP URI to locate resources for the SCAP strorage APIs.
169      * SCAP URI follows the syntax of a standard URI.
170      * </p>
171      * <p>
172      * Those restrictions are applied to the SCAP URI.
173      * <ul>
174      * <li> If the protocol for the URI is file://, then allowd charecter sets are [a-zA-Z0-9-._]</li>
175      * <li> URI cannot be longer than a 256 length string </li>

190      *          Maximum length for a pathname is 255.
191      *          <p>(note: ../ is not allowed in the file path. '*' and '?' are also not supported.)</p>
192      *          </th>
193      *       </tr>
194      *       <tr class="odd">
195      *          <th>file://usb:[index]/</th>
196      *          <th>

198      *          If the path to the file destination is not found, directories for the file path will be automatically created.<br>
199      *          Maximum length for a pathname is 255.
200      *          <p>(note: ../ is not allowed in the file path. '*' and '?' are also not supported.)</p>
201      *          </th>
202      *       </tr>
203      *       <tr>
204      *          <th>file://sdcard:[index]/</th>
205      *          <th>
206      *          Locate to a file in SD card device at SD card port:[index]. A SD card storage device should be connected to the port.<br>
207      *          If the path to the file destination is not found, directories for the file path will be automatically created.<br>
208      *          Maximum length for a pathname is 255.
209      *          <p>(note: ../ is not allowed in the file path. '*' and '?' are also not supported.)</p>
